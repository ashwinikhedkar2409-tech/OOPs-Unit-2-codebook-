List of Programs and description:-
1. **Basic Single Inheritance** – To demonstrate inheritance using a base class and a derived class.

2. **Protected Member Access** – To demonstrate how a derived class accesses protected members of a base class.

3. **Public versus Private Inheritance** – To demonstrate the effect of different inheritance modes on member accessibility.

4. **Multilevel Inheritance** – To demonstrate inheritance through multiple levels of classes.

5. **Hierarchical Inheritance** – To demonstrate multiple derived classes inheriting from a single base class.

6. **Multiple Inheritance** – To demonstrate a class inheriting from two base classes.

7. **Multiple-Inheritance Ambiguity** – To resolve ambiguity using the scope-resolution operator.

8. **Constructor and Destructor Order** – To demonstrate the order of constructors and destructors in inheritance.

9. **Parameterized Base Constructor** – To demonstrate initialization of a base class using a derived-class constructor.

10. **Function Overriding** – To demonstrate overriding a virtual function in a derived class.

11. **Abstract Class** – To demonstrate an abstract class using a pure virtual function.

12. **Virtual Base Class and Diamond Inheritance** – To resolve duplicate-base ambiguity using a virtual base class.

13. **Friend Class** – To demonstrate access to private class members using a friend class.

14. **Nested Class** – To demonstrate the creation and use of a class inside another class.

15. **Vehicle Rental System** – To develop an inheritance-based vehicle rental system using derived classes and polymorphism.

16. **Employee Payroll System** – To develop a payroll system using abstract classes, inheritance, and function overriding.
